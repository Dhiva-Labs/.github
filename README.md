# Dhiva Labs · .github

This repository holds the profile shown on the [Dhiva Labs organization page](https://github.com/Dhiva-Labs).

| Path | What it is |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organization profile itself |
| [`scripts/profile_stats.py`](scripts/profile_stats.py) | Collects the numbers and draws the languages card |
| [`.github/workflows/profile.yml`](.github/workflows/profile.yml) | Runs daily and on changes: writes `profile/numbers.json`, `profile/languages.svg` and the pinned project cards in `profile/pins/` |

The numbers cover public, non-fork repositories only. To refresh them by hand, run the **Org profile cards** workflow from the Actions tab.

Everything Dhiva Labs builds is listed on the [organization page](https://github.com/Dhiva-Labs). For anything else, write to [reachout@dhivalabs.com](mailto:reachout@dhivalabs.com).
